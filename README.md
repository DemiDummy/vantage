# Vantage

Squad tactics on high ground. A browser tactics RPG prototype: two squads fight on a 3D tile arena where height,
facing and the turn order decide everything. Five classes, fifteen subclasses, gear that changes how a unit plays,
items, six arenas and an AI opponent.

**Play it at https://demidummy.github.io/vantage/** (desktop browser, mouse and keyboard).

Click tiles and buttons, right-click or Esc to go back, Q/E rotate the camera, mouse wheel zooms, drag or WASD pans,
Space ends a turn. The "?" button in battle explains the rules.

This repo only holds the built game. It's published from a private source repo by `tools/release-pages.sh`.
